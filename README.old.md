## 🔨 What I'm building right now

### 🔥 Heater *(working name)* — Question classifier with semantic understanding

My first real end-to-end NLP project, currently in training phase.

**Goal.** Build a small model that classifies the **type of question** a user is asking — and eventually understands the **meaning** behind it, not just the words.

**Approach, in three stages:**
1. **Stage 1 — Classical classifier.** Train a model on a question dataset to recognize question categories. Iterate on logistic regression, random forests, evaluate properly. *← I am here.*
2. **Stage 2 — Embeddings.** Add a semantic layer (TF-IDF first, then word embeddings) so the model understands meaning, not just keywords.
3. **Stage 3 — Integration.** Connect the trained model to a portfolio website (currently offline, work in progress) as an interactive Q&A feature.

Why this project matters to me: it forces me to handle the full ML lifecycle — dataset, preprocessing, training, evaluation, iteration, deployment — rather than just running notebook cells.
